# Simulmedia

> Simulmedia is a technology-driven TV advertising company. Its platforms (Performance TV, the TV+ media-buying platform, and Skybeam self-serve) let advertisers plan, buy, and measure campaigns across linear TV, connected TV (CTV), and games. Through PlayerWON, Simulmedia also runs an in-game rewarded-video engagement and monetization platform for free-to-play console and PC games, backed by a developer API and a first-party Unity/Unreal SDK.

This llms.txt was generated by the API Evangelist enrichment pipeline from the Simulmedia public developer surface, live probes of the PlayerWON API host, and the open-source PlayerWON SDK. Last updated 2026-08-13.

## Products
- [Performance TV](https://www.simulmedia.com/): Tech-powered TV ad planning and buying for advertisers and agencies.
- [TV+ media-buying platform](https://www.simulmedia.com/platform/tv-advertising-platform): AI-powered platform for linear and CTV campaign planning, activation, and measurement.
- [Skybeam](https://www.skybeam.io/): Simulmedia's self-serve CTV and traditional TV buying platform. The app lives at https://platform.simulmedia.com/ — the public pricing page now redirects there, so plans are visible only after sign-in.
- [PlayerWON](https://www.playerwon.com/): In-game rewarded-video engagement and monetization for free-to-play games.

## API
- PlayerWON API — base URL https://game.simulmedia-apis.com — OAuth2 client-credentials; brokers rewarded-video ad opportunities into games.
- Operations: `POST /token`, `POST /session`, `POST /opportunity`, `PUT /start/{receipt}`, `PUT /progress/{receipt}`, `PUT /complete/{receipt}`, `PUT /abort/{receipt}`, `POST /sdk/telemetry`.
- The `Receipt` returned by `POST /opportunity` is the key for the whole playback lifecycle.
- No OpenAPI, GraphQL, AsyncAPI or MCP server is published. No `/.well-known/` document is served on any host.
- Errors are `{"message": "<text>"}` — not RFC 9457, and with no machine-readable error code.
- No published rate limits, no sandbox environment, and no test credentials: integration is against production from the first call.

## SDKs
- [PlayerWON SDK (Unity, Unreal, Go reference server)](https://github.com/Simulmedia/playerwon-sdk): First-party game-engine SDK, Apache-2.0. Latest tagged release v1.0.0 (2022-10-03); the UE5.5 plugin work (through 2025-03-24) is unreleased on main.
- Unreal plugin is also distributed free on Epic's FAB store.
